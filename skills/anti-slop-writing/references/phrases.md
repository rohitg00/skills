# Phrase Cleanup Reference

Use this file when a draft sounds generic at the sentence level. The goal is not to ban every phrase forever. The goal is to notice phrases that usually announce, inflate, soften, or perform instead of saying something specific.

## Throat-Clearing Openers

These delay the point. Cut them and start with the claim, scene, or example.

| Avoid | Better move |
|---|---|
| Here's the thing | State the thing |
| Let's talk about | Start the topic |
| I want to talk about | Start the topic |
| In today's world | Name the real context |
| In a world where | Name the real context |
| When it comes to | Use the subject directly |
| At its core | Say the core claim |
| The reality is | Say the reality |
| The truth is | Say the truth |
| It is worth noting | Note it |
| It turns out | Say what happened |
| The problem is that | Name the problem |
| What I find interesting is | Say the interesting part |
| Can we talk about | Make the point |
| Let me be clear | Be clear |

Rewrite rule: if removing the opener does not change meaning, remove it.

## Empty Emphasis

These try to create force without adding evidence.

- Full stop.
- Period.
- Let that sink in.
- Make no mistake.
- Read that again.
- This matters.
- This matters because...
- That is the point.
- That's it.
- That's the post.
- I'll say it again.
- You need to hear this.
- I cannot stress this enough.

Rewrite rule: replace emphasis with a detail, example, or consequence.

## Generic Importance Words

These words often hide the missing noun.

| Weak word | Ask |
|---|---|
| important | Important to whom, and why? |
| powerful | What changed? |
| meaningful | What did it mean in practice? |
| valuable | Who valued it? |
| significant | How large, costly, rare, or useful? |
| transformative | What was different after? |
| robust | What failed less often? |
| seamless | Which step disappeared? |
| scalable | What load, team size, or process grew? |
| efficient | What took less time, money, or effort? |

Rewrite rule: replace the adjective with the observable thing.

## Business Fog

Use plain verbs unless the audience expects the term.

| Avoid | Prefer |
|---|---|
| leverage | use |
| utilize | use |
| unlock | create, reveal, make possible |
| optimize | improve, tune, reduce, increase |
| streamline | simplify, shorten, remove |
| enable | let, allow, make possible |
| empower | let, give, help |
| navigate | handle, deal with |
| unpack | explain, examine |
| explore | look at, test, compare |
| delve into | examine, explain |
| deep dive | analysis, review |
| ecosystem | market, tools, community |
| landscape | market, field, situation |
| journey | process, story, path |
| game-changer | change, improvement |
| paradigm shift | change |
| best-in-class | specific advantage |
| cutting-edge | new, current, experimental |
| frictionless | easier, fewer steps |
| drive impact | change the metric |
| align stakeholders | get people to agree |
| move the needle | improve the result |
| double down | commit, increase |
| circle back | return |
| touch base | talk |

Rewrite rule: use the shortest verb that still means the same thing.

## Softeners And Intensifiers

These usually weaken the sentence. Cut first, restore only if the meaning changes.

- really
- very
- just
- actually
- literally
- honestly
- genuinely
- simply
- basically
- kind of
- sort of
- somewhat
- quite
- rather
- incredibly
- deeply
- truly
- fundamentally
- inherently
- importantly
- crucially
- interestingly
- arguably
- arguably one of

Rewrite rule: remove the softener. If the sentence becomes too blunt, add context instead of padding.

## AI Assistant Markers

These make prose sound like generated output or a generic answer.

- It is important to note that...
- It is crucial to understand...
- This highlights the importance of...
- This underscores the need for...
- In conclusion...
- To summarize...
- By embracing...
- By leveraging...
- Whether you are X or Y...
- From X to Y...
- In an era of...
- In the ever-evolving world of...
- This comprehensive guide...

Rewrite rule: cut the scaffolding and move to the concrete claim.

## Social Engagement Bait

Use a real ask instead of engagement bait.

| Avoid | Better |
|---|---|
| Thoughts? | What would you change in this draft? |
| Agree? | Where does this break in your experience? |
| Drop a comment | Tell me which part is unclear |
| Comment YES | Reply if you want the checklist |
| Like and share | Send this to someone running into this |
| Hot take | State the take |
| Unpopular opinion | State the opinion |
| Nobody talks about | Name the overlooked thing |
| The uncomfortable truth | State the truth |

Rewrite rule: ask for a specific response only when the post benefits from one.

## Vague Authority Claims

These sound confident but cannot be checked.

- Everyone knows...
- Nobody understands...
- Most people miss...
- The best teams always...
- Great leaders never...
- The future belongs to...
- This is the only way...
- The market rewards...
- The data proves...

Rewrite rule: narrow the claim or name the evidence.
